## I. АРХИТЕКТУРНЫЙ АУДИТ

   - `app/dialog/` - чистая бизнес-логика диалога

   - Проверено: нет циклических импортов

## IV. STANDARD DOWNLOADER

### ✅ Реализация

1. **SHA256 проверка:**
   - ✅ `calculate_hash()` использует `hashlib.sha256()`
   - ✅ Проверка при загрузке: `find_by_hash()`
   - ✅ Проверка целостности: `verify_integrity()`

2. **Версионирование:**
   - ✅ `StandardVersion` хранит `version_hash`
   - ✅ Новая версия создается при изменении hash
   - ✅ История версий в БД

3. **Обработка ошибок:**
   - ✅ Try-except блоки в `upload_standard()`
   - ✅ Rollback при ошибке: `self.db.rollback()`
   - ✅ Логирование ошибок

### ⚠️ Проблемы

1. **Нет retry механизма:**
   - **Файл:** `app/standards/manager.py`
   - **Проблема:** При ошибке загрузки нет повторных попыток
   - **Рекомендация:** Добавить retry с exponential backoff

2. **Нет проверки структуры данных:**
   - **Проблема:** После парсинга PDF нет валидации структуры
   - **Рекомендация:** Добавить schema validation для `parsed_data`

3. **Синхронный парсинг:**
   - **Проблема:** `PDFParser.parse()` может блокировать event loop
   - **Рекомендация:** Вынести в thread pool или использовать async библиотеку

## VIII. SECURITY

1. **SQLAlchemy ORM:**
   - ✅ Все запросы через ORM: `session.query(Standard).filter(...)`
   - ✅ Параметризованные запросы: `filter_by(user_id=user_id)`

2. **SQLite:**
   - ✅ Используются параметры: `cursor.execute('...', (param,))`
   - ✅ Нет f-strings в SQL запросах (в основном)

### ⚠️ Потенциальные проблемы

1. **F-strings в SQL:**
   - **Файл:** `app/storage/migrations.py:16`
   - **Проблема:** `cursor.execute(f"PRAGMA table_info({table_name})")`
   - **Риск:** Низкий (table_name из внутреннего кода)
   - **Рекомендация:** Использовать параметры: `cursor.execute("PRAGMA table_info(?)", (table_name,))`

2. **F-strings в SQL:**
   - **Файл:** `app/storage/migrations.py:99`
   - **Проблема:** `cursor.execute(f"ALTER TABLE ... ADD COLUMN {col_name} {col_def}")`
   - **Риск:** Низкий (col_name из конфигурации)
   - **Рекомендация:** Whitelist разрешенных имен колонок
