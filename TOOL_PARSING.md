# Парсинг и сохранение инструментов

## ✅ Что добавлено

### 1. Парсинг названий инструментов

#### `app/core/parser.py` - Расширенный парсер
- **Распознавание ISO кодов**: CNMG, WNMG, TNMG, DNMG, VNMG, SNMG и т.д.
- **Распознавание производителей**: SANDVIK, KENNAMETAL, ISCAR, SECO, WALTER и др.
- **Распознавание марок/градаций**: P25, M15, GC1020, YBC251 и т.д.
- **Извлечение радиуса из номера**: CNMG 120408 → радиус 0.8 мм

**Новые поля в ParsedData:**
- `tool_name` - название инструмента (CNMG 120408)
- `tool_manufacturer` - производитель (SANDVIK)
- `tool_grade` - марка/градация (P25)

### 2. Распознавание инструментов с фотографий

#### `app/core/image_parser.py` - Парсер изображений
- **OCR распознавание**: использует Tesseract OCR для извлечения текста
- **Предобработка изображений**: увеличение контраста и резкости
- **Парсинг текста**: поиск ISO кодов, производителей, марок
- **Определение типа инструмента**: по ISO коду определяет форму и тип

**Поддерживаемые форматы:**
- JPEG, PNG, BMP и другие форматы, поддерживаемые PIL

**Примеры распознавания:**
- Фото этикетки CNMG 120408 → `tool_name: "CNMG 120408"`, `tool_type: "токарный проходной (ромбическая 80°)"`
- Фото с маркировкой SANDVIK P25 → `manufacturer: "SANDVIK"`, `insert_grade: "P25"`

### 3. Сохранение неизвестных инструментов в БД

#### `app/services/tool_saver.py` - Сервис сохранения инструментов
- **Автоматическое сохранение**: если инструмент не найден в базе знаний
- **Определение характеристик**: автоматически определяет тип, материал по марке
- **Сохранение в две таблицы**:
  - `ToolRecord` - основная таблица инструментов
  - `ToolLibrary` - справочник инструментов

**Что сохраняется:**
- Название инструмента (ISO код)
- Тип инструмента (определяется автоматически)
- Материал пластины
- Марка/градация
- Радиус пластины
- Производитель
- Дополнительная информация (из OCR, из текста)

### 4. Интеграция с Telegram ботом

#### `app/bot/image_handler.py` - Обработчик изображений для Telegram
- **Обработка фото**: скачивание и парсинг фотографий инструментов
- **Форматирование результатов**: красивое отображение распознанных данных
- **Сохранение в БД**: автоматическое сохранение распознанных инструментов

#### `app/bot/telegram_bot.py` - Обновлен
- **Обработчик фотографий**: `@dp.message(F.photo)` - обрабатывает фото инструментов
- **Сохранение из текста**: автоматически сохраняет инструменты, упомянутые в тексте
- **Расширенный ExtractedData**: добавлены поля `tool_name`, `tool_manufacturer`, `tool_grade`

## 🚀 Как использовать

### Отправка фотографии инструмента

1. Пользователь отправляет фото инструмента в бот
2. Бот распознает текст с фото (OCR)
3. Извлекает информацию об инструменте:
   - ISO код (CNMG, WNMG и т.д.)
   - Производитель (SANDVIK, KENNAMETAL и т.д.)
   - Марку (P25, M15 и т.д.)
   - Радиус (из номера инструмента)
4. Сохраняет инструмент в БД
5. Показывает результат пользователю

**Пример сообщения бота:**
```
✅ ИНСТРУМЕНТ РАСПОЗНАН С ФОТОГРАФИИ

📌 Название: CNMG 120408
🔧 Тип: токарный проходной (ромбическая 80°)
🏭 Производитель: SANDVIK
💎 Материал пластины: твердый сплав
⭐ Марка: P25
📏 Радиус: 0.8 мм

💾 Инструмент сохранён в базу данных (ID: 123)

🎯 Уверенность распознавания: 85%
```

### Упоминание инструмента в тексте

Пользователь может написать:
```
"CNMG 120408, сталь, токарный ЧПУ, с Ø100 до Ø90"
```

Бот:
1. Распарсит название инструмента (CNMG 120408)
2. Проверит, есть ли он в базе знаний
3. Если нет - сохранит в БД
4. Использует для расчета режимов резания

## 📦 Установка зависимостей

Для работы с изображениями нужно установить:

```bash
# Python библиотеки
pip install pytesseract Pillow

# Tesseract OCR (системная зависимость)
# Windows: скачать с https://github.com/UB-Mannheim/tesseract/wiki
# Linux: sudo apt-get install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng
# macOS: brew install tesseract tesseract-lang
```

Или использовать файл `requirements_ocr.txt`:
```bash
pip install -r requirements_ocr.txt
```

## 🔧 Настройка Tesseract

После установки Tesseract нужно указать путь (если не в PATH):

```python
import pytesseract
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'  # Windows
```

Или через переменную окружения:
```bash
export TESSDATA_PREFIX=/usr/share/tesseract-ocr/4.00/tessdata
```

## ⚠️ Ограничения

1. **OCR точность**: зависит от качества фото, освещения, угла съемки
2. **Распознавание языков**: поддерживает английский и русский (нужно установить языковые пакеты Tesseract)
3. **ISO коды**: распознаются только стандартные ISO коды инструментов
4. **Производители**: список ограничен популярными производителями
