# 🔧 Исправления архитектурных проблем

## ✅ Исправлено

### 1. **Различение типов сообщений**
- ✅ Приветствия (`привет`, `ку`, `але`) → `GREETING` → режим `CHAT`, FSM отключен
- ✅ Вопросы о возможностях (`что ты можешь`) → `META_CAPABILITIES` → режим `CHAT`, FSM отключен
- ✅ Инженерные запросы → `ENGINEERING` → режим `ENGINEERING`, FSM включен
- ✅ Стандартные детали (`ГОСТ`, `ОСТ`) → `STANDARD_PART` → режим `PROJECT`, FSM включен

### 2. **Распознавание ГОСТ/ОСТ как класс задачи**
- ✅ Добавлен `Intent.STANDARD_PART`
- ✅ Паттерны для распознавания: `ГОСТ 7798-30`, `ОСТ 1 31102-80`, `DIN 912`, `ISO 4014`
- ✅ Извлечение типа и номера стандарта
- ✅ Приоритет проверки стандартов ДО инженерных запросов

### 3. **Отдельный сценарий для стандартных деталей**
- ✅ Создан `StandardService` для работы со стандартами
- ✅ База стандартов в `data/standards/*.yaml`
- ✅ Автоматическое определение типа детали, материала, операций
- ✅ Запрос только переменных параметров (диаметр, длина, количество)

### 4. **Отключен авто-старт FSM**
- ✅ FSM запускается ТОЛЬКО если:
  - Интент = `ENGINEERING` с уверенностью >= 0.6
  - Или интент = `STANDARD_PART`
  - Или явные команды: режим, рассчитай, обработка
- ✅ При приветствии FSM НЕ запускается
- ✅ Предположения делаются ТОЛЬКО если FSM активен и есть минимальные данные

### 5. **Fallback для неизвестных интентов**
- ✅ После 2 раз подряд `UNKNOWN` → показывается меню выбора:
  - Рассчитать режимы резания
  - Сделать деталь по ГОСТ
  - Помочь с технологией

### 6. **Улучшен AssumptionEngine**
- ✅ Не делает предположения без минимальных данных
- ✅ Не предполагает станок по умолчанию (только если есть операция или стандарт)
- ✅ Не предполагает режим без диаметров
