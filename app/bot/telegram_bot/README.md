# Рефакторинг Telegram бота

## Структура модулей

```
telegram_bot/
├── __init__.py          # Экспорт основных компонентов
├── main.py              # Точка входа, инициализация, глобальные переменные
├── utils.py             # Вспомогательные функции (парсинг, извлечение данных)
├── formatters.py        # Форматирование сообщений
├── keyboards.py         # Все клавиатуры
├── context_storage.py   # Единая функция сохранения контекста
├── unit_of_work.py      # Unit of Work паттерн для транзакций
└── handlers/
    ├── __init__.py      # Регистрация всех обработчиков
    ├── commands.py      # Команды (/start, /help, /reset, /status, /history, /stats)
    ├── messages.py      # Основной обработчик текстовых сообщений
    ├── photos.py        # Обработка фото (инструменты, спектры)
    └── callbacks.py     # Обработка кнопок (callbacks)
```

## Выполненные улучшения

### ✅ 1. Создана модульная структура
- Разделен большой файл на логические модули
- Каждый модуль отвечает за свою область ответственности
- Упрощена навигация и поддержка кода

### ✅ 2. Единая функция получения контекста
- `get_user_context()` - единая точка доступа к контексту
- Автоматический приоритет хранилищ: context_manager → file_storage → context_repository → user_contexts
- Автоматическое создание контекста если не существует

### ✅ 3. Unit of Work для транзакций
- Класс `UnitOfWork` для атомарных операций
- Поддержка контекстного менеджера (`with`)
- Автоматический откат при ошибках

### ✅ 4. Вынесены утилиты
- Парсинг номеров работ
- Извлечение параметров из текста
- Проверка опыта оператора
- Парсинг режимов из подписей к фото

### ✅ 5. Вынесены форматирование и клавиатуры
- Все функции форматирования в `formatters.py`
- Все клавиатуры в `keyboards.py`
- Упрощена поддержка и переиспользование

### ✅ 6. Исправлены магические числа
- `MAX_TELEGRAM_MESSAGE_LENGTH = 4096` - константа вместо магического числа
- `TELEGRAM_SAFE_MESSAGE_LENGTH = 4000` - безопасная длина с запасом

## Использование

### Запуск бота:
```python
from app.bot.telegram_bot.main import main
import asyncio

asyncio.run(main())
```

### Получение контекста:
```python
from app.bot.telegram_bot.utils import get_user_context

context = await get_user_context(user_id)
```

### Сохранение контекста:
```python
from app.bot.telegram_bot.context_storage import save_context_safe

save_context_safe(context, user_id, db_session)
```

### Использование Unit of Work:
```python
from app.bot.telegram_bot.unit_of_work import UnitOfWork

with UnitOfWork(db_session=session) as uow:
    uow.register_context(context, user_id)
    # ... другие операции
    uow.commit()  # Автоматически при выходе из with
```

## Преимущества новой структуры

1. **Модульность** - каждый файл <500 строк, легко навигировать
2. **Переиспользование** - утилиты и форматирование доступны везде
3. **Тестируемость** - модули можно тестировать независимо
4. **Поддерживаемость** - изменения локализованы в конкретных модулях
5. **Расширяемость** - легко добавлять новые обработчики и функции

## Миграция

Старый файл `telegram_bot.py` остается для обратной совместимости.
Постепенно все обработчики будут перенесены в новую структуру.
