# NLP baseline

Модуль `cnc_ml` содержит базовый intent-классификатор TF-IDF + LinearSVC и отдельную функцию оценки NER. Он объединяет проверенную NLP-логику из прежнего `cnc_ai_ecosystem` с основным CNC-репозиторием.

## Окружение

Создайте отдельное окружение, чтобы не смешивать эксперимент с ML-Agents или зависимостями бота:

```powershell
python -m venv .venv-ml
.\.venv-ml\Scripts\Activate.ps1
python -m pip install -r requirements-ml.txt
python -m unittest discover -s tests/ml -v
```

## Данные и обучение

JSON-файл содержит два списка одинаковой длины: `queries` — тексты, `intents` — строковые метки классов. Необходимы минимум два класса и два примера каждого класса. Каждая часть разбиения должна вмещать все классы. Повторяющиеся тексты с учётом регистра и пробелов отклоняются до разбиения.

```powershell
python -m cnc_ml train path/to/reviewed_dataset.json --output artifacts/intent-model --seed 42
python -m cnc_ml predict artifacts/intent-model "подбери инструмент для сверления"
```

Набор данных нужно подготовить самостоятельно: проверить лицензию, разметку и отсутствие персональных данных. Пример в команде показывает интерфейс, а не поставляемый benchmark.

Сохраняются `intent.joblib` и `validation.json`. Артефакт содержит pipeline и карту меток. Отчёт содержит seed, размеры частей, accuracy, macro-F1, confusion matrix и оценки по классам. Векторизатор обучается только на train-части. Сходные перефразировки и связанные записи всё ещё требуют группового разбиения при подготовке реального benchmark.

Модель возвращает метку без искусственной вероятности: SVM-margin не является калиброванной уверенностью. Отдельная test-выборка и подбор гиперпараметров этим CLI не реализованы.

Загружайте joblib только из доверенного источника: формат может исполнять код при десериализации. Версии окружения при обучении и загрузке должны совпадать. Каталог `artifacts/` исключён из новых Git-коммитов.

## Оценка сущностей

`cnc_ml.ner_metrics.evaluate_entities(predictions, references)` принимает списки документов, каждый из которых содержит сущности вида `{"type": "TOOL", "start": 0, "end": 5}`. Смещения задаются в общей для предсказаний и разметки системе координат; интервал `[start, end)`. Совпасть должны документ, тип и обе границы. Повторение одной и той же сущности внутри документа считается одной записью. При пустом знаменателе precision/recall равны нулю.

Это span-level оценка; токенизация, извлечение сущностей и token accuracy не входят в этот evaluator.
