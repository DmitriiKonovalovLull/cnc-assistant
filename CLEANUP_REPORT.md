### ✅ Исправлена ошибка SQLAlchemy

**Проблема:** Поле `metadata` зарезервировано в SQLAlchemy Declarative API

**Исправление:**
- `app/standards/models.py`: `metadata` → `version_metadata`
- `app/standards/repository.py`: параметр `metadata` → `version_metadata`
- `app/standards/manager.py`: использование обновлено
